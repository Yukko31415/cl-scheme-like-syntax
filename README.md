# cl-scheme-like-syntax

このパッケージは、Common Lispで初学者が学習する際に発生する命名や構文、仕組みから来る難しさを解消し、利用をさらに容易にするためのライブラリです。
具体的には

	- 破壊的関数の末尾統一（\*!）
	- 述語関数の末尾統一（\*?）
	- 一般化参照の末尾統一（\*@）
	- sequence型を扱うstring系関数をstring\*に改名
	- if, cond, caseでelseを使用可能に
		- さらに => シンボルでプロシージャを使用可能に
		- 加えて、if-let\*, when-let\*, and-let\*などを追加
	- 型変換関数の命名統一（foo->bar）
	- 非推奨関数の排除（*-if-not系関数）
	- など

を、schemeを参考にした統一された命名に変換することによってより使いやすくすることを目的としています。
まだ開発段階にあり、内容は破壊的に変更されることがあります。
SBCLでの動作のみが確認されています。
