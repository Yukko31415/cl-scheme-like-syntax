# cl-scheme-like-syntax

このパッケージは、Common Lispで初学者が学習する際に発生する命名や構文、仕組みから来る難しさを解消し、利用をさらに容易にするためのライブラリです。

具体的には

- 破壊的関数の末尾統一（`*!`）
- 述語関数の末尾統一（`*?`）
  - また、述語関数が真偽値のみを返すように変更
- 一般化参照の末尾統一（`*@`）
- `sequence`型を扱う`string`系関数を`string*`に改名
- `if`, `cond`, `case`で`else`を使用可能に
  - さらに `=>` シンボルでプロシージャを使用可能に
  - 加えて、`if-let*`, `when-let*`, `and-let*`などを追加
- 型変換関数の命名統一（`foo->bar`）
- 非推奨関数の排除（`*-if-not`系関数）
- など

を、schemeを参考にした統一された命名に変換することによって、より使いやすくすることを目的としています。

まだ開発段階にあり、内容は破壊的に変更されることがあります。

SBCLでの動作のみが確認されています。

注意: number->string、およびstring->numberは現在動作が不安定です。使用した場合、想定外の挙動が発生する可能性があることを考慮してご利用ください。
